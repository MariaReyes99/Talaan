# Can a client that uses another payroll system still use Talaan?

## English

**Can a client that uses another payroll system still use Talaan?**

Yes. Set the client’s payroll to Another payroll system, then each month upload its payroll register under Compliance → Import payroll. Talaan checks the SSS, PhilHealth, Pag-IBIG and tax figures against its own tables, flags differences, and prepares the government files from the register.

## Tagalog

**Puwede pa bang gumamit ng Talaan ang client na may ibang payroll system?**

Oo. Itakda ang payroll ng client sa Ibang payroll system, saka buwan-buwan i-upload ang payroll register nito sa Compliance → Import payroll. Susuriin ng Talaan ang SSS, PhilHealth, Pag-IBIG at buwis gamit ang sarili nitong table, ituturo ang pagkakaiba, at ihahanda ang mga file para sa gobyerno mula sa register.

## 中文

**使用其他工资系统的客户还能用 Talaan 吗？**

可以。将该客户的工资来源设为“其他工资系统”，每月在“合规 → 导入工资”中上传工资明细表。Talaan 用自己的费率表核对 SSS、PhilHealth、Pag-IBIG 和税款，标出差异，并根据明细表准备政府申报文件。
