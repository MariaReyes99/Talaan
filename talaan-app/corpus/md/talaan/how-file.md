# Can Talaan file with BIR, SSS, PhilHealth or Pag-IBIG for me?

## English

**Can Talaan file with BIR, SSS, PhilHealth or Pag-IBIG for me?**

Not yet. Talaan prepares each file and shows where to upload it. After you upload and pay on the agency portal, enter the reference number on the Files page to mark it as filed. Direct filing through an accredited partner is planned for Phase 2.

## Tagalog

**Kaya bang mag-file ng Talaan sa BIR, SSS, PhilHealth o Pag-IBIG para sa akin?**

Hindi pa. Inihahanda ng Talaan ang bawat file at ipinapakita kung saan ia-upload. Pagkatapos mag-upload at magbayad sa portal, ilagay ang reference number sa page ng Mga file para markahang na-file. Ang direktang pag-file sa pamamagitan ng accredited partner ay nakaplano sa Phase 2.

## 中文

**Talaan 能替我向 BIR、SSS、PhilHealth 或 Pag-IBIG 申报吗？**

暂时不能。Talaan 会准备好每个文件并告诉你上传到哪里。在机构网站上传并缴款后，在“文件”页面输入参考号即可标记为已申报。通过认证合作伙伴直接申报计划在第二阶段推出。
